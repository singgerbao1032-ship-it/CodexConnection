PPT为16:9，含完整海报、逐字分层、无字背景三页。
16个汉字各为一个独立透明图层，另有竖线与5个绘画元素：右侧马与花海画窗整体、左上画窗、蝴蝶、两片花瓣。
文字为透明PNG，可移动缩放，不能直接改写文字内容；书法相连处按连接处分界。马与花海保留为一组画窗，未逐朵花拆分。
高清由源图高质量放大，不另行调色；不代表恢复源图未记录的细节。文字和绘画遮挡的底图采用同色水彩补绘。
