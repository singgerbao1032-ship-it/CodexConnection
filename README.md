# 迎新晚会海报文件

版本：删除指定长笔触的海报，保留原色与原字形。

- `poster-every-character.pptx`：高清逐字分层版，约20.4 MiB。三页：高清整图、逐字分层、无字背景。81个字符和1个分隔线可单独移动与缩放。
- `poster-compatible.pptx`：约4.3 MiB兼容版，保留原图像素和逐字对象，不嵌入额外的4K插值副本。
- `every-character-assets.zip`：81个字符及分隔线的独立透明PNG与位置清单。
- `poster-hd.png`：4096×5969像素完整海报，无损PNG。
- `background-hd.png`：同尺寸去字背景，无损PNG。

在GitHub文件页面选择 **Download raw file** 下载，不要下载网页HTML。若仓库为私有，请使用有访问权限的账号登录。

文字保留为透明图片，可移动和缩放，不能直接改写文字内容。高分辨率文件由1039×1514像素原图高质量放大，不代表恢复源图未记录的真实细节。去字区域按原水彩风格补绘，绘画主体作为整体背景保留。

文件校验值见 `SHA256SUMS.txt`。
