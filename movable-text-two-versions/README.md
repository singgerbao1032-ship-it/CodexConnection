# 两版文字可移动PPT

本目录提供用户指定的两个版本，各一份独立单页PPT。页面16:9，绘画背景和字形均保留4K像素素材。

1. [下载草书版（主题略缩小）](cursive-smaller-movable.pptx)：对应 user-layout-cursive-smaller。
2. [下载原PDF字体去马版](original-pdf-no-horse-movable.pptx)：对应 user-pdf-only-remove-horse。

每份PPT含10个独立透明文字图层：化、梦、为、马、哲、韵、生、花各一层；底部“2026四院联合迎新晚会”一组；主办信息一组。可以单独拖动和缩放，Ctrl多选可一起移动。选择窗格已按具体字名命名。
背景已去除所有文字，移开图层后不会留下重复原字。背景的原文字覆盖区域采用同色水彩补绘，其余区域保留源图。字形保留为透明PNG图片，不能直接改写文字内容。

已验证：每份一页、11个对象（1张背景+10个透明文字图层）、无移动锁定、移动后保存再打开坐标保持；PPT结构完整。
